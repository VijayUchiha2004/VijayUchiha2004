### Things I've built

**[secure-password-manager](https://github.com/VijayUchiha2004/secure-password-manager)**
My first "okay, security actually matters" project. Node, Express and MySQL, with JWT logins, bcrypt for passwords, and AES-256-GCM for the vault itself. I learned more from breaking it than from building it.

**[crop-disease-detection](https://github.com/VijayUchiha2004/crop-disease-detection)**
A CNN that looks at a pepper, potato or tomato leaf and tells you what's wrong with it. Wrapped in a Streamlit app so a farmer doesn't need to know what a CNN is.

**[AI-Finance-Tracker](https://github.com/VijayUchiha2004/AI-Finance-Tracker)** and **[AI-Finance-Manager](https://github.com/VijayUchiha2004/AI-Finance-Manager)**
Experiments with putting LLMs on top of boring money data to see if it makes budgeting less painful.

**BharatCare**
Disease prediction + local environmental risk + AI explanations in multiple languages. The one I'm proudest of.
